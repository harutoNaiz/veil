## 1. Deviations and risks
- **Dataset: Open Images V7, validation + test subsets, human-verified image-level labels** (`Source=verification`, Confidence 1 = present, 0 = verified absent). Why: 20k classes cover 100 concrete words; verified negatives give real lookalikes; it is a different source from the bank (COCO), so "unseen" is strong. LVIS was rejected: its images ARE COCO images (bank overlap) and its train json is 350 MB zipped (RAM). Checked 2026-10-06 with curl: the CSVs on `storage.googleapis.com/openimages/...` answer 200; images answer on **plain http** `http://open-images-dataset.s3.amazonaws.com/{subset}/{ImageID}.jpg` (~5 s latency each; https timed out; Flickr thumbnails 404). Use coco.py's `_get` (http.client), 32 threads. **Fallback** if -Mini fetches < 1 img/s: validation subset only; if still too slow, BLOCKED + human decision (LVIS val minus bank ids).
- **Licences:** images CC BY 2.0 per the metadata `License` column (recorded per image with author + landing URL); labels CC BY 4.0. An image whose licence URL is not CC BY/CC BY-SA 2.0 is dropped at selection.
- **Safety:** drop any image with a positive label among BLOCK = {Brassiere, Swimwear, Bikini, Lingerie, Underpants, Undergarment, Miniskirt, Nudity} (names that exist in the class list). Agents never open images or thumbnails.
- **Labels are not exhaustive.** A "clean" screen for w = no card with a positive label for w's classes (+ their descendants in `bbox_labels_600_hierarchy.json`). Unlabelled positives inflate false-cover; this is reported as a failure class, never fixed by relabelling after the freeze.
- **Unseen words.** BANNED (all forms) = the tuning words {cat, spider, snake, dog, fox}, the 7.1 dev words {buffalo, umbrella, pizza, motorcycle, giraffe, kite, broccoli, surfboard, clock}, PT-7.1 lookalikes {cow, horse, cattle, bull, ox, bison, yak} and near-forms {kitten, puppy, motorbike, moped, scooter, pony}. The 7.1 dev words become the **dev split** (unlimited runs); the 100 words are the **test split** (≤ 5 runs).
- **Disk/RAM:** CSVs (~185 MB) are streamed with `csv`, only rows for candidate/BLOCK/TAG classes kept, then deleted after freeze. Images: fetched → rotated → resized to ≤ 320 px → `cache/` (JPEG q85, ~130 MB, resumable) → deleted after embedding, except 64 thumbnails (128 px). Kept: pieces fp16 (~55 MB), manifest, lock, replay mp4 (~10 MB).
- **Heavy cost:** ~5,200 images (~17 min fetch) + ~1,750 screens × 22 pieces (~38k embeds, GPU, ~25-40 min). Resumable. One model process at a time (fetch_embed, then evaluate; never together).
- **Method changes after attempt 1** must be global (§2 params); if adopted, porting to Kotlin + `AutoCalParityTest` is a follow-up the orchestrator runs (gradle-locked); 7.2.2 only builds the tooling.

## 2. Shared interfaces (verbatim)
**Paths:** code `workshop/twin/bench/`; data `data/bench/{smoke,mini,v1}/` (git-ignored); src cache `data/bench/src/`. Committed outputs: `workshop/twin/bench/manifest-v1.json`, `bench-v1.lock.json`, `attempts.jsonl`, `licences-v1.csv`.
**Words file** `workshop/twin/bench/candidates.json` (A writes; fixed before any download): `{"banned":[...],"block":[...],"tags":["Drawing","Cartoon","Illustration","Painting","Toy","Art"],"dev":["snake","buffalo","umbrella","pizza","motorcycle","giraffe","kite","broccoli","surfboard","clock","cat","spider"],"categories":{"animal":[...],"object":[...],"food":[...],"vehicle":[...]}}`; each candidate = `{"word":"zebra","oi":"Zebra"}` (`oi` = exact DisplayName in `oidv7-class-descriptions.csv`, case-insensitive; >1 MID → skipped as ambiguous). ≥ 40 candidates per category, in this priority order:
- animal: zebra elephant lion tiger bear monkey rabbit squirrel owl penguin duck swan goose parrot eagle chicken pig sheep goat camel kangaroo deer butterfly bee frog turtle lizard crab jellyfish dolphin shark whale starfish snail ladybug hedgehog koala panda hamster alpaca ostrich
- object: chair bottle book laptop television guitar piano backpack handbag suitcase sunglasses hat boot watch lamp vase candle "teddy bear" balloon flag bench couch bed ladder scissors teapot mug "wine glass" mirror drum violin camera "mobile phone" headphones microphone toothbrush tent "christmas tree" skateboard "tennis racket" knife
- food: hamburger "hot dog" sandwich cake "ice cream" doughnut cookie bread croissant pancake waffle muffin pasta sushi salad apple banana orange strawberry grape lemon pineapple watermelon tomato carrot potato cucumber mushroom cheese "french fries" coffee wine beer cocktail pretzel popcorn burrito taco pumpkin peach
- vehicle: car bus truck van taxi ambulance bicycle train tram boat sailboat canoe yacht airplane helicopter tank tractor limousine "golf cart" snowmobile "jet ski" forklift "fire engine" "police car" wheelchair "school bus" "pickup truck" minivan "sports car" jeep bulldozer excavator gondola submarine barge "hot air balloon" unicycle segway stroller rocket
**Selection rule** (count-only, before any image is seen): per category take candidates in order whose word ∉ BANNED and with ≥ 40 eligible positives, until 25; a short category is filled round-robin (animal→object→food→vehicle) from the others' next candidates; `select` prints the final balance. Eligible image = licence OK, no BLOCK label, Flickr photo id not in the bank (see disjoint). Per word: positive queue = eligible Conf=1 images sorted by sha256(word+ImageID), up to 60; lookalike queue = eligible Conf=0 images for w (and not Conf=1), same order, up to 20. Pool queue = eligible images with ≥ 1 positive label and NO positive for any test/dev word class, same order (key "pool"), up to 450. Fetch takes queues in order until **36 positives, 8 lookalikes per word, 300 pool** succeed (mini: 12 test words = first 3 per category + first 4 dev words, 12/2/30; smoke: 2 test words, 4/1/6, validation only). Dev words use the same queues/sizes, split "dev".
**Screens:** 360×780 feed, 3 cards (reuse `public_set._split_heights`, `_bars`, `SIZE`, `APPS`; A writes `compose.render_feed(rng, photos: list[Image.Image], dark: bool) -> (Image, [photo_rect x3], [card_rect x3])`). Fetched images sorted by ImageID, shuffled with `random.Random(72)`, chunked in threes (last chunk padded with pool images). Screen i: dark = i%3==0, app = APPS[i%5]. Every screen is fully determined by the manifest.
**Manifest** `manifest-v1.json` (canonical: `json.dumps(obj, sort_keys=True, separators=(",",":"))`, UTF-8; lock = its sha256):
```
{"version":1,"name":"v1","dataset":"Open Images V7 (validation,test) human-verified image-level labels","labelLicence":"CC BY 4.0",
 "words":[{"word":"zebra","category":"animal","split":"test","mids":["/m/0898b"],"descMids":[..]}],
 "images":[{"id":"fe600639ac5f36c1","source":"openimages","subset":"validation","url":"http://open-images-dataset.s3.amazonaws.com/validation/fe600639ac5f36c1.jpg",
   "landing":"...","license":"https://creativecommons.org/licenses/by/2.0/","author":"...","flickrId":"15340259497","rotation":0,"sha256":"<raw bytes>",
   "pos":["zebra"],"neg":["horse"],"roles":["pos:zebra"|"look:horse"|"pool"],"tags":["Drawing"]}],
 "screens":[{"i":0,"app":"instagram","dark":true,"cards":["<imageId>",x3],"photoRects":[{x,y,w,h}x3]}]}
```
`bench-v1.lock.json` = `{"manifestSha256":"..","frozenAt":"<iso>","words":100,"devWords":n,"images":n,"screens":n}`. `freeze` refuses to overwrite a lock with a different hash (exit 2).
**Pieces** `data/bench/<name>/pieces.npz`: `vecs` f16 (S*22, 768) unit rows from `run.describer_pieces(desc)` order; `regions` = the one shared `make_pieces` list for 360×780, as `regions.json`. `fmt.py` (A, FIRST):
```python
@dataclass
class Bench: manifest: dict; lock: dict; vecs: np.ndarray; regions: list[dict]; dir: Path
def canonical(obj: dict) -> bytes ; def manifest_hash(obj: dict) -> str
def write_bench(dir: Path, manifest: dict, vecs: np.ndarray, regions: list[dict]) -> str   # also writes lock, returns hash
def load_bench(dir: Path) -> Bench        # raises if sha256(canonical(manifest)) != lock.manifestSha256
def screen_vecs(b: Bench, i: int) -> np.ndarray      # float32 (22, 768)
def labels_for(b: Bench, word: str) -> list[dict]    # ScreenLabels: one box per card positive for word, clean = no box
```
**Metrics** (per word, per mode light/balanced/strict, via `judge.judge` + `judge.to_findings` + `workshop.eval.score_screens.score` on `labels_for(w)`): recall, precision, cleanFalseCover; plus `lookalikeFC` = share of lookalike cards for w that a hide region overlaps. Word passes iff Balanced recall ≥ 0.90 and cleanFalseCover ≤ 0.05. **gateShare** = passing words / test words. Concept card = `autocal.compile_auto(word, enc, bank, vocab)`.
**Global method params** `workshop/twin/bench/params.json` (B): `{"templates":[...],"quantilesPerMille":{...},"k":8,"margin":0.0}` defaulting to autocal's constants; `evaluate --params` applies them by overriding `autocal` module constants for the run. NO key may name a word.
**Attempts** `attempts.jsonl` (B), one line per TEST run, appended BEFORE scoring: `{"n":1,"at":iso,"manifestSha256":..,"bankId":..,"paramsSha256":..,"note":"baseline"}`, then a result line `{"n":1,"gateShare":..,"passing":k}`. n > 5 → exit 2 `ATTEMPTS EXHAUSTED`. Dev runs are not logged and see only dev words.
